# Eduk Product Roadmap

The following roadmap outlines the evolution of Eduk from its current MVP state to a "Magnifique" market leader in educational technology.

## Phase 1: MVP (Current)
- Core app blocking via Accessibility Service.
- Manual question entry and mock AI Vision infrastructure.
- Local parent dashboard and basic email reports.
- US K-12 academic alignment.

## Phase 2: AI & Vision Integration (Q4 2026)
- **Full Vision API Integration**: Live processing of textbook photos into questions.
- **Video Analysis**: Support for short videos showing multiple pages or diagrams.
- **Adaptive Difficulty**: AI adjusts question complexity based on the student's historical accuracy.

## Phase 3: Manager Ecosystem (Q1 2027)
- **Eduk Manager Web Portal**: Advanced analytics and remote configuration from any browser.
- **Multi-Child Support**: Manage multiple student profiles from a single manager account.
- **Push Notifications**: Real-time alerts when a child completes a difficult study session.

## Phase 4: Expansion (Q2 2027)
- **iOS Implementation**: Utilizing Apple's Screen Time API (FamilyControls).
- **Gamification 2.0**: Marketplace for parents to reward "Eduk Points" with real-world incentives.
- **Teacher Integration**: Allow teachers to upload "Eduk Packs" for their students.
