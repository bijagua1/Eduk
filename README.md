# Eduk: The Next-Gen Screen Time & Learning Ecosystem

**Eduk** is a high-tech Android application designed for the US market, revolutionizing how parents manage their children's screen time by integrating artificial intelligence and academic development.

## 🚀 The Vision: "Learn First, Play Later"
Eduk is not just a blocking app; it's an AI-driven educational tutor that acts as a gatekeeper to entertainment. Before accessing restricted apps (YouTube, TikTok, Games), the student must prove their knowledge.

## 🧠 High-Tech Features
- **AI Book Scan (Vision AI)**: Parents can take a photo or video of any textbook or study material. Eduk's AI engine instantly generates relevant, age-appropriate questions based on that specific content.
- **Smart App Blocking**: Utilizes official Android APIs (Device Policy & Usage Stats) to restrict access to entertainment apps while keeping essential tools available.
- **Real-Time Parent Reports**: Automated performance reports are sent to the manager's account, providing insights into study habits, accuracy, and time earned.
- **US Academic Alignment**: Content and difficulty levels are tailored to the US K-12 education system, covering Math, Science, English Language Arts (ELA), History, and Geography.

## 🛠 Tech Stack
- **Language**: Kotlin (Modern Android Development)
- **UI**: Jetpack Compose with Material 3
- **Architecture**: Clean Architecture + MVVM
- **Database**: Room (Local Persistence)
- **AI Engine**: Integration-ready for OpenAI/Google Gemini Vision APIs
- **Backend/Reporting**: Secure API integration for remote reporting

## 📂 Project Structure
- `app/`: Main Android application source code.
- `docs/`: Comprehensive technical and product documentation.
- `assets/`: UI assets and report templates.
